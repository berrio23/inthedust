# In The Dust 

By Bethany Collinge

(c) 2025, Bethany Collinge

A playable build of this game is available [here](https://berrio23.github.io/inthedust/).

### Playing a local build

Serve the index.html file using a local web server e.g. (with Node installed)

```
    npx serve .
```

### Controls

W A S D or arrow keys to move
SPACE to interact
